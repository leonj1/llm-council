# Quick Test Command Reference

## Prerequisites
```bash
# Start backend (required!)
python -m backend.main

# Install test dependencies
pip install -e ".[test]"
```

## Quick Commands

```bash
# Quick check (< 1 min)
./run_tests.sh quick

# Full test (10-15 min, makes API calls)
./run_tests.sh full

# All tests
pytest backend/tests/ -v

# Quick server check only
pytest backend/tests/test_movie_script_integration.py::test_server_is_running -v

# Full integration with output
pytest backend/tests/test_movie_script_integration.py::test_movie_script_workflow_end_to_end -v -s

# Skip slow tests
pytest backend/tests/ -m "not slow" -v

# Integration tests only
pytest backend/tests/ -m integration -v
```

## Debugging

```bash
# Verbose output with prints
pytest backend/tests/ -v -s

# Very verbose (shows diffs)
pytest backend/tests/ -vv

# Stop on first failure
pytest backend/tests/ -x

# Show local variables on failure
pytest backend/tests/ -l

# Increase timeout
pytest backend/tests/ --timeout=1800
```

## Markers

```bash
# Run by marker
pytest -m slow
pytest -m integration
pytest -m unit

# Exclude by marker
pytest -m "not slow"
pytest -m "not integration"
```
